Substitution cipher

A substitution cipher replaces each letter with another letter. The original letter positions remain unchanged.

A B C
→
D E F
Key concepts
Letters are replaced, not rearranged.
The shift value is the secret key.
Same input letter always maps to the same output letter.
Learning use only
Classical ciphers are historically important but are not secure by modern standards. Do not use them to protect passwords or sensitive information.
